# C++ Phone Book Management System

A C++ console application developed using Dev-C++ during my first semester to manage personal contacts.

## Features
- **Add Number:** Store new phone numbers in the system.
- **Search Number:** Look up saved contact numbers.
- **Exit:** Safely close the program.

## Technologies Used
- **Language:** C++
- **IDE / Environment:** Dev-C++

## How to Run
1. Open the project folder in Dev-C++ (or any standard C++ IDE).
2. Compile and run `PhoneBook.cpp` (Press `F11` in Dev-C++).
3. Follow the menu prompts in the console window.
